控制题的地基是电机。不管上层是循迹、云台还是平衡，最后推的都是电机。这篇把「PWM 驱动 → 编码器测速 → PID 速度环」这条最常用的链路完整打通。

## PWM 与 H 桥

直流电机用 **H 桥驱动**（TB6612、DRV8833 最常见）。接线要点：

- **IN1/IN2** 决定方向（IN1=1, IN2=0 正转；反之反转；同为 0 刹车）
- **PWM 接使能脚**（TB6612 的 PWMA/PWMB）或一个 IN 脚，决定转速——占空比 = 电压百分比
- **STBY 接 3.3V**（TB6612 必须拉高才工作，新手的经典迷之故障）

PWM 频率选 **10k~20kHz**：低于 10kHz 电机啸叫（人耳能听到、还会发热）；高于 20kHz 开关损耗上升、驱动芯片发热。STM32 定时器预分频配置时算好，常用 16kHz 附近。

## 编码器测速（M 法）

增量式编码器（500 线常见）接定时器的**编码器模式**（TIM3 的 CH1/CH2 是经典接口），硬件自动四倍频，中断里读计数器即可。M 法测速 = 固定周期内数脉冲：

```c
/* 每 T_SAMPLE 秒执行一次（如 10ms），由定时器中断驱动 */
static int16_t last_cnt = 0;
int16_t cnt = (int16_t)TIM_GetCounter(TIM3);
TIM_SetCounter(TIM3, 0);
int16_t delta = cnt - last_cnt;  last_cnt = cnt;
/* 换算：PPR=编码器线数(500)，4倍频，减速比 GEAR=30 */
float rev_per_s  = delta / (4.0f * 500.0f * 30.0f) / T_SAMPLE;   /* 圈/秒 */
float speed_mm_s = rev_per_s * WHEEL_CIRC_MM;                     /* 轮周长 mm */
```

三个注意点：

- **用 int16 做差**：计数器可能溢出，int16 的环形差（`cnt - last_cnt`）天然正确处理溢出，别用 `int` 后取绝对值。
- **减速比必须算**：电机轴转 30 圈轮子才转 1 圈（常见 30:1），漏了减速比测速会差 30 倍，PID 直接失控。
- **M 法低速精度差**：低速时脉冲少、量化误差大；速度环目标很低时考虑 T 法（测脉冲间隔），电赛一般 M 法够用。

## 把 PID 接起来

用上一篇的增量式 PID 做速度环，SysTick 1ms 计数做调度：

```c
void SysTick_Handler(void)
{
    static uint32_t tick = 0;
    if (++tick % 10 == 0) {      /* 10ms 速度环周期 */
        float speed = Motor_GetSpeed();          /* 编码器换算的 mm/s */
        float pwm_out = PID_Incremental(&pid, target_speed, speed);
        Motor_SetPWM(pwm_out);                    /* 含方向与限幅 */
    }
}
```

`Motor_SetPWM` 里做方向分配：正占空比 → IN1=1/IN2=0 正转；负 → 反转；并夹在 ±100 内。目标速度 `target_speed` 由上层（串级外环或遥控指令）更新。

## 调参实录（示范格式）

实车调参一定要记录，不然第二天参数就丢了。照这个格式写：

```
日期: 2026-08-14  车: 四轮差速  电池: 11.1V 满电
---- 左轮速度环 ----
Kp=10: 阶跃 500rpm 超调 25%，1s 稳定，可接受
Kp=20: 振荡发散，回退
Kp=12 + Kd=8: 超调 8%，0.6s 稳定 ← 采纳
---- 右轮 ----
Kp=12 + Kd=8: 稳态差 3%（左右轮摩擦不一致），Ki=2 后消除
注意: 电池掉到 9V 时 Kp=12 出现轻微振荡，比赛前用满电工况
```

这是范本——你实车调的时候按同样格式往这篇里补，调参经验和数据就是最值钱的内容。

## 常见坑

- **编码器计数溢出**：用 int16 环形差，别用绝对值（见上文）。
- **左右轮不对称**：两轮摩擦、减速箱阻尼不同，同一组参数两边表现不一样。分别标定，必要时加前馈。
- **PWM 方向与编码器方向逻辑不一致**：正转给正 PWM 但编码器数负脉冲，速度环会正反馈发散。上电先手动转轮子验证符号。
- **共地问题**：驱动板、编码器、主控不共地，读数跳变、电机抖。先把地线理清楚。
