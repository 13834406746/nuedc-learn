电赛控制题里，PID 是出场率最高的算法，没有之一。小车循迹、云台稳定、飞行器悬停、电机调速，底层全是它。这篇文章把位置式 PID 讲透：它在做什么、代码怎么写、坑在哪里。

## PID 在做什么

先看整体结构——这是一个典型的闭环控制框图：目标值进入控制器，控制信号驱动执行器，被控对象的输出又被传感器测回来参与误差计算。PID 就工作在「误差 → 输出」这个环节：

             stages={['目标值', '误差', 'PID 控制器', '执行器', '被控对象']}
             feedbackFrom={4} />

控制问题的本质：有一个**目标值**（setpoint，比如目标速度 1000 rpm），有一个**反馈值**（feedback，编码器测到的实际速度），我们控制一个**执行器**（PWM 占空比）。PID 就是根据误差

```
e = setpoint - feedback
```

计算出执行器输出 u 的公式。三个字母各管一件事：

| 项 | 管什么 | 直觉 |
|----|--------|------|
| **P** 比例 | 现在的误差 | 误差大就使劲推，误差小就轻轻推。光有 P，往往到不了目标（稳态误差） |
| **I** 积分 | 过去的误差累积 | 把「一直差那么一点」的账算上，慢慢补上缺口。代价是容易超调、振荡 |
| **D** 微分 | 误差的变化趋势 | 误差正在快速缩小时提前收力，抑制超调。代价是放大噪声 |

记住这个分工，后面的调参方法论全靠它。

## 从连续到离散

连续形式的 PID 是：

```
u(t) = Kp·e(t) + Ki·∫e(τ)dτ + Kd·de/dt
```

单片机里没有积分和微分，只有定时中断——**在固定采样周期 dt 下做数值近似**：

```
u[k] = Kp·e[k] + Ki·(Σe)·dt + Kd·(e[k]−e[k−1])/dt
```

代码实现时通常把 dt 直接吸收进 K_i 和 K_d（下文代码就是这么做的），这样定时器中断里每拍只需要三次加减乘。**注意前提：采样周期必须固定**——这也是为什么 PID 一定要在固定周期定时器里调用，而不是在主循环里随便调。

## C 代码实现

以 STM32 标准库风格，结构体 + 初始化 + 计算三步走：

```c
typedef struct {
    float kp, ki, kd;
    float integral;      /* 积分累加（已含 dt） */
    float prev_err;      /* 上次误差 */
    float int_max;       /* 积分限幅：抗饱和 */
    float out_max;       /* 输出限幅：执行器物理极限 */
} PID_t;

void PID_Init(PID_t *pid, float kp, float ki, float kd,
              float int_max, float out_max)
{
    pid->kp = kp;  pid->ki = ki;  pid->kd = kd;
    pid->integral = 0.0f;  pid->prev_err = 0.0f;
    pid->int_max = int_max;  pid->out_max = out_max;
}

/* 固定周期调用（如 10ms 定时器），周期抖动会直接破坏 D 项 */
float PID_Positional(PID_t *pid, float setpoint, float feedback)
{
    float err = setpoint - feedback;

    pid->integral += err;
    if (pid->integral >  pid->int_max) pid->integral =  pid->int_max;
    if (pid->integral < -pid->int_max) pid->integral = -pid->int_max;

    float d = err - pid->prev_err;
    pid->prev_err = err;

    float out = pid->kp * err + pid->ki * pid->integral + pid->kd * d;
    if (out >  pid->out_max) out =  pid->out_max;
    if (out < -pid->out_max) out = -pid->out_max;
    return out;
}
```

逐段看：

- **struct 为什么这样设计**：所有状态（积分、上次误差）都装进结构体，意味着同一个 PID_t 可以被多个控制环复用（两个轮子、内外环），互不干扰。加一个 `init` 函数把参数和状态一起初始化，换参数只需要改一处。
- **积分限幅 = 抗积分饱和**：积分项无限制累积会「胀死」——误差一直存在时积分越滚越大，误差翻转后要花很久才能消化掉，表现为明显的滞后和振荡。把积分限制在 ±int_max（一般取输出限幅的 1/3~1/2），这是位置式 PID 最重要的工程细节。
- **输出限幅**：执行器有物理极限（PWM 占空比 0~100%、电机电流有限），输出必须限制，否则映射到 PWM 时会有截断误差积累。

<PidDemo />

做三个实验，每个实验猜完再拖：

1. **只开 P**（Kp=2，Ki=0，Kd=0）：看稳态误差。加大 Kp 误差会变小，但永远不会到 0——这就是纯 P 的宿命。
2. **加 I**（Kp=2，Ki=8，Kd=0）：误差被消除，但注意超调出现了。I 越大，消除越快，超调也越大。
3. **加 D**（Kp=4，Ki=12，Kd=0.3）：对比没 D 的情况，超调明显被压下去。再把 Kd 拉到 2 以上试试——超调反而变大甚至发散。**D 不是越大越好**。

指标栏里的「调节时间」和「超调量」就是控制课里评价性能的两个核心指标，做题评分很多时候评的就是它们。

## 常见坑

- **积分风暴**：输出已经饱和（比如电机堵转、PWM 已到 100%），积分还在累积。解决：积分限幅（代码里已有），更彻底的是积分分离——误差超过阈值就不积分。
- **D 项放大噪声**：传感器稍微抖一下，D 项就剧烈跳变。解决：先对反馈做低通滤波再微分，或者干脆用增量式（下一篇）。
- **控制周期不固定**：在主循环里随手调 PID，周期抖动直接改变 Kd 和 Ki 的实际效果（公式里含 dt）。解决：PID 必须在固定周期定时器中断里调用。
- **正反馈接反**：编码器方向、PWM 方向接反，表现为输出越大误差越大、瞬间发散。上电先手动验证反馈符号。
