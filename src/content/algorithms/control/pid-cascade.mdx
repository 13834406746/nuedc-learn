单环 PID 能解决大多数问题，但电赛里有两类经典场景单环搞不定，需要**串级 PID**：小车走直线/循迹（方向环 + 速度环），云台/飞行器姿态（角度环 + 角速度环）。串级是控制类拿奖的分水岭技术，必须掌握。

## 为什么单环不够

单环的问题是**扰动只能靠同一个环慢慢消化**。以云台为例：只用一个「角度环」，目标角度 → 直接算舵机/电机 PWM。此时如果有人在云台上拍一下（扰动），角度环要等角度偏差出现才能反应——而角度偏差是位置量，变化慢，反应自然慢。

串级的思路：把「被控量」分层。**内环控制变化快、能直接被执行器影响的量（角速度、线速度），外环控制最终目标量（角度、位置）**。外环的输出不直接给执行器，而是作为内环的目标值：

```
外环（慢）：目标位置/角度 → 目标速度/角速度
内环（快）：目标速度 → PWM
```

扰动进来时，先打在内环的量上（速度瞬间变化），内环立刻把它压回去——**扰动在内环就被吃掉，根本来不及传到外环**。这就是串级抗扰性能好的根本原因。

## 电赛里的两种典型串级

**① 小车：外环方向、内环速度（差速）**

```
外环 PID：目标轨迹偏差(循迹偏差/航向角偏差) → 目标角速度
内环 PID：目标角速度 → 左右轮 PWM（差速）
```

外环 20~50ms 跑一次（视觉/陀螺仪更新慢），内环 5~10ms 跑一次（编码器更新快）。循迹车、平衡车都用这个结构。

**② 云台：外环角度、内环角速度**

```
外环 PID：目标角度(靶标位置/陀螺仪目标) → 目标角速度
内环 PID：目标角速度 → 舵机/电机 PWM
```

内环用 MPU6050 陀螺仪的角速度反馈，外环用 DMP 解算的角度反馈。视觉追踪靶标时，外环目标角度来自视觉偏差，反应慢但稳；内环负责对抗手抖、机械回差，反应快。**2023 E 题追靶云台就是教科书式的这种结构**（见赛题解析板块）。

## 代码结构

```c
PID_t inner, outer;   /* 两个独立 PID 实例 */

/* 每个控制周期（比如 10ms）执行一次： */
void ControlLoop(void)
{
    /* 外环：位置/角度误差 → 内环目标（角速度） */
    float outer_out = PID_Positional(&outer, target_pos, cur_pos);
    /* 内环：角速度误差 → 执行器 PWM */
    float pwm        = PID_Positional(&inner, outer_out, cur_rate);
    Motor_Set(pwm);
}
```

代码上没有任何魔法，就是把两个 PID 串起来。真正的难度在调参顺序和周期设置。

## 调参顺序：先内后外

串级调参的铁律：**先调内环，再调外环**。

1. 内环单独调：给内环一个阶跃目标速度，把 P 调到「快速跟随、不振荡」。此时可以暂时断开外环。
2. 内环调好后，固定内环参数，再调外环：外环输出的是内环的目标，给外环阶跃位置目标，按单环方法调外环 P、加 D 抑振、最后加 I 消静差。
3. **内环带宽不足，外环怎么调都没用**——外环的响应速度上限就是内环的带宽。内环响应慢，外环加大 P 只会振荡。

关于「带宽」的直觉：用上一篇文章的 PidDemo 可以体会——内环就相当于「速度环」仿真，把 Kp 调小，整个系统响应就慢；把这个慢系统当内环，外环再激进也没用。调参更系统的流程见《PID 调参方法论》。

## 常见坑

- **内外环周期不一致**：内环周期必须 ≤ 外环（内环更快）。如果写反了，内环跟不上外环的指令变化，系统发疯。外环 10ms、内环 5ms 是常用搭配。
- **外环输出没限幅**：外环输出是内环目标值，必须限制在传感器的合理量程内（比如角速度 ±200°/s），否则内环收到离谱目标会饱和震荡。
- **两个环的反馈别混**：外环反馈是角度/位置（绝对量），内环反馈是速度（变化量），用反了系统直接发散。接反检测：上电先手推云台/小车，观察输出方向是否对抗运动。
