视觉题的 90% 工作可以浓缩成一句话：**把「我要的东西」从图像里分离出来，再算它的位置**。分离的核心手段就是二值化——视觉的第一课，也是最常被低估的一课。

## 像素、通道与灰度化

图像就是像素矩阵。彩色图每个像素 3 个通道，OpenCV 里顺序是 **BGR**：

```
像素 (x, y) = (B, G, R)   每个通道 0~255
```

很多算法不需要颜色，先把彩色图转灰度。灰度化不是随便平均，是按人眼亮度感知加权：

```
gray = 0.299·R + 0.587·G + 0.114·B
```

绿色权重最高（人眼对绿最敏感），蓝色最低。OpenCV 一行搞定：

```python
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
```

## 二值化

二值化就是给每个像素发一张「入场券」：亮度 ≥ 阈值 → 255（白），否则 → 0（黑）：

```python
_, bin = cv2.threshold(gray, 100, 255, cv2.THRESH_BINARY)
cv2.imshow('binary', bin)
```

就这么简单——但**阈值选多少，是电赛视觉题最容易翻车的地方**。阈值选对了，黑线白底一清二楚；选错了，赛场上灯光一变整个识别就崩。

## 阈值怎么选

**第一步：看直方图。** 把灰度直方图画出来（`cv2.calcHist`），理想的图是两个明显的峰（背景峰 + 目标峰），阈值取两峰之间的谷底：

```python
import matplotlib.pyplot as plt
hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
plt.plot(hist)
plt.show()
```

**第二步：理解光照的影响。** 直方图的两个峰之间分得越开，阈值越好选。光照不均匀会让「背景峰」变成一大片斜坡，单阈值怎么选都切不干净——这就是下面演示要让你直观看到的东西。

**自动阈值**（`cv2.THRESH_OTSU` 大津法、自适应阈值 `cv2.adaptiveThreshold`）能在两峰分得开时自动找谷底。但电赛场景下光照可控，**手动定一个固定阈值往往最稳**——自动算法在复杂光照下会做出你意想不到的决定，而手动阈值的行为完全可预期。

## 常见坑

- **光照不均**：补光（加灯带/匀光板）比任何算法都靠谱。记住顺序：先物理手段，再算法手段。
- **黑线还是白线**：场地背景是浅色就找黑线，是深色就找白线，永远选与背景对比度最大的一方，别跟场地过不去。
- **忘转灰度**：`cv2.threshold` 直接喂彩色图会报错，记得先 `cvtColor`。
- **阈值写死在代码里**：调参时用滑块（OpenMV 有阈值编辑器，OpenCV 可以写个带 trackbar 的小脚本），调好再写死，别每次改代码重新烧录。
