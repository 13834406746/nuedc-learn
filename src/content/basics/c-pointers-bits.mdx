单片机开发不是「写代码」，是「直接和硬件打交道」——寄存器、地址、中断。教材里的 C 语言 90% 用不上，但下面这 20% 不掌握，写 STM32 代码会处处碰壁。这篇只讲进单片机必需的部分，都是电赛写代码每天要用的。

## 指针：地址就是一切

指针存的是**地址**。STM32 编程里到处是地址——外设寄存器、DMA 缓冲区、数组名。

```c
uint8_t data = 42;
uint8_t *p = &data;    /* p 存 data 的地址 */
*p = 43;               /* 通过地址改值 */
```

寄存器操作的本质就是「往固定地址写值」。标准库封装好了，但你得看懂：

```c
/* GPIOA 的 ODR 寄存器地址 + 偏移，标准库里就是这么定义的 */
#define GPIOA_ODR  (*(volatile uint32_t *)0x4001080C)
```

逐层拆解这个宏：`0x4001080C` 是地址 → `(uint32_t *)` 把它变成指针 → `volatile` 告诉编译器别优化 → `*` 解引用，于是 `GPIOA_ODR = 1` 就是往该地址写值。看不懂这个宏，看谁写的代码都像天书。

## 数组和指针的暧昧关系

数组名就是首元素地址：

```c
uint8_t buf[16];
buf[3] = 5;            /* 等价于 *(buf + 3) = 5 */
```

串口收发的缓冲区、DMA 的搬运目标，全是数组。记住：**把数组传给函数时，传的是地址，函数里改的就是原数组**。

## 位运算：操作寄存器的唯一手段

寄存器里的每一位都代表一个开关，位运算就是精准地拨动它们：

| 运算 | 符号 | 用途 |
|------|------|------|
| 与 | `&` | 清零指定位：`REG &= ~(1 << 3)` |
| 或 | `\|` | 置位：`REG \|= (1 << 5)` |
| 异或 | `^` | 翻转：`REG ^= (1 << 2)` |
| 左移 | `<<` | 构造位掩码 |

STM32 里最常写的三句：

```c
/* 第 5 位置 1（比如打开某个功能位） */
RCC->APB2ENR |= (1 << 2);

/* 第 3 位清 0（比如关闭某个功能） */
GPIOA->CRL &= ~(1 << 3);

/* 读某一位的状态（比如读取电平） */
if (GPIOA->IDR & (1 << 1)) { /* 第 1 位为 1 */ }
```

标准库的 `GPIO_SetBits`、`GPIO_ResetBits` 内部就是干这个。位运算不熟，寄存器配置写不动，代码也看不懂——这是必须过关的基本功。

## volatile：防编译器「聪明」

编译器会优化「看起来没变」的变量，但硬件会变：

```c
volatile uint8_t rx_flag;   /* 中断里置位，主循环里读 */

void ISR(void) { rx_flag = 1; }          /* 中断里写 */
while (!rx_flag) { }                     /* 主循环里读，永远循环？ */
```

不加 `volatile`，编译器可能把 `rx_flag` 优化进寄存器缓存，主循环永远读不到中断改的新值——死循环。**中断共享变量、寄存器映射、DMA 标志位，一律加 volatile**。这也是本站《串口进阶》篇里 ringbuf 指针必须 volatile 的原因。

## 结构体：把一堆参数打包

外设初始化参数多，标准库都用结构体打包：

```c
typedef struct {
    uint16_t Prescaler;      /* 预分频 */
    uint16_t Period;         /* 周期 */
    uint16_t Pulse;          /* 脉宽 */
} TIM_TimeBaseInitTypeDef;

TIM_TimeBaseInitTypeDef t = { 7199, 9999, 500 };
```

`typedef` 给结构体起别名（`TIM_TimeBaseInitTypeDef`），省得每次写 `struct xxx`。自定义 PID 参数、帧协议、传感器数据，都用结构体——本站算法篇的 `PID_t` 就是这个模式。

## 常见坑

- **指针没初始化**：野指针崩溃。声明即初始化（`= NULL` 或指向明确目标）。
- **位运算优先级**：`REG &= ~(1<<3)` 的 `<<` 优先于 `&`，但 `&` 低于 `==`。拿不准就加括号。
- **volatile 漏加**：中断/硬件共享变量不声明 volatile，行为随机。规则：谁碰硬件谁加。
- **数组越界**：`buf[16]` 写 `buf[16]` 不报错，但会把下一个变量/返回地址踩坏，表现为「莫名奇妙的崩溃」。调试时先查数组边界。
